Questions

Which slicers does it work with?

Bambu Studio and OrcaSlicer, plus Orca-based slicers like QIDI Studio and ElegooSlicer. PrusaSlicer works too.

How big can I go?

There's no limit. A bigger print just means more pieces, and you'll see the finished size before anything gets cut.

Can I use two printers with different bed sizes?

Yes. Each piece goes to the smallest printer it fits on. The hand was split between my P1P and A1.

Does one license cover Windows and Mac?

Yes. You get both versions and can use it on two computers. The Mac version needs Apple silicon.

Do I need to know 3D modeling?

No. If you can open a file in your slicer, you can use this.
